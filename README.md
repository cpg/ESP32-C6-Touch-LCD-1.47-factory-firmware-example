# Factory firmware for the Waveshare ESP32-C6-Touch-LCD-1.47 board 

This is a recently-compiled (and verified as working) firmware of the [ESP32-C6-Touch-LCD-1.47](https://docs.waveshare.com/ESP32-C6-Touch-LCD-1.47) board.

It corresponds to the example called [01_factory](https://docs.waveshare.com/ESP32-C6-Touch-LCD-1.47/ESP-IDF#example-01_factory) in the web site and works on a recent (08/2026) up to date VSCode and extensions.

It does require an older ESP-IDF (I used 5.5.5) as well as an older LVGL (8.4).

~It would be great if it were to be ported to recent IDF and LVGL versions 😃~

A port to IDF 6.0.2 and LVGL 9.5.0 in branch [`idf-6-lvgl-9`](https://github.com/cpg/ESP32-C6-Touch-LCD-1.47-factory-firmware-example/tree/idf-6-lvgl-9). 😃
